# Site 421 Club

Site vitrine statique (HTML, CSS, JS, sans build), style « Lilas Pop » de l'app (police Outfit, lilas, pastels).
Publié par GitHub Pages : https://club421app.github.io/421club

## Voir le site en local

```
python3 -m http.server 8000
```

Puis ouvrir http://localhost:8000

## Structure

- `index.html` : l'accueil (titre et téléphone, les cinq modes au défilement, chiffres, Raymond, collection, questions, téléchargement)
- `assets/css/site.css` : couleurs et typo en haut du fichier
- `assets/js/site.js` : animations au défilement (sans bibliothèque)
- `assets/img/` : visuels en WebP
- `support.html`, `confidentialite.html`, `privacy.html`, `conditions.html`, `mentions-legales.html` : pages légales et aide
- `signature/` : signature mail
